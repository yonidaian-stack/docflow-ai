# DocFlow AI — Prototype interactif

Maquette SaaS en français, charte bleu nuit / bleu électrique / violet.

## Lancer
Ouvrir `index.html` dans un navigateur, sans installation.

## Démonstration
- Tableau de bord et indicateurs fictifs
- Boîte documentaire avec glisser-déposer (nom des fichiers uniquement)
- Simulation de scan photocopieur
- Documents et validation manuelle
- Explorateur et connecteurs cloud simulés
- Assistant IA simulé
- Règles de classement et configuration de stockage
- Responsive ordinateur/mobile

**Attention :** prototype UX uniquement. Aucun OCR, IA, authentification, stockage sécurisé ou connexion Google/Microsoft. Ne pas utiliser avec des documents confidentiels.
